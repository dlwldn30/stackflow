# v0.1.1 External Project Validation

Date: 2026-08-26

## Goal

Validate StackFlow against a non-demo Spring Boot application without modifying the target project's source or build files.

The validation target was a local Java 21 / Spring Boot 3.4.1 application with Spring MVC, Spring Security, JPA, Flyway, PostgreSQL with PostGIS, and Redis.

The generated profile contained 38 instrumented classes and 87 public methods. The target application was restarted with OpenTelemetry Java Agent 2.31.0 and the generated profile resource ID.

## Reproduction Notes

- Run StackFlow backend natively so it can read the target project's host path.
- Provide reachable PostgreSQL/PostGIS and Redis instances required by the target application.
- Use the complete generated Agent command. Exporting only the profile response's OTEL environment map does not attach the Agent; `JAVA_TOOL_OPTIONS=-javaagent:<path>` is required.
- If the target uses `server.servlet.context-path`, include it in the request target base URL. Static mapping paths remain controller-relative.
- A JDBC or Redis automatic span may not contain code location metadata. StackFlow does not copy a parent method location onto that infrastructure span.
